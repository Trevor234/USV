## 3. 核心验证与实验结果摘要

### 3.1 数据集与 GP 模型（WP3–WP4）
- **采集规模与质量**：`60` 条 mismatch + `6` 条 nominal 轨迹全数接收（拒绝 `0`），`18163` 个 0.2 s mismatch 窗口 + `1816` 个 nominal 窗口；`clock resync = 0`，名义数据残差 `max_abs <= 2.220e-16`（零残差门禁 GP 输出 `0.000e+00`）。

  - 未见过组合失配 `heldout_combination`（+5% mass, +10% Xu, +10% Nr）：`sparse_gp_m64` RMSE 从 `0.008877` 降至 **`0.002214`**；2.0 s 多步开环 rollout 位置/速度误差分别从 `0.05280 m / 0.07983` 降至 `0.03392 m / 0.02604`。
  - Python vs C++（`gp_numeric_parity.json`）：`sha256_match=True`，`max_abs_mean_diff=5.684e-14`，`ood_flags_exact_match=True`。

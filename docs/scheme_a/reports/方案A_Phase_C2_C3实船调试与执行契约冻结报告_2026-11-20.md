## 三、Phase C2 5项硬注错测试过程与实测遥测数据

### 3.1 F0：差速转向符号与闭环控制基线
- **测试动作**：向 `/usv/mission/waypoints_local` 注入 3 组航向角偏差航点（直线前进、左偏 +95°、右偏 -95°），闭环求解 20 步 Acados NMPC 并由 `p1_regulator` 输出通道覆盖。
- **实测数据**：
  - 直线向前（`yaw_error = 0.0°`）：Acados 平均求解耗时 `0.516 ms`，推力指令 `TL/TR ~ [10.2, 15.6] N`，RC 输出 `CH1=1498..1506, CH3=1623..1684`。
  - 左转（船头 `90.02°`，目标 `-174.98°`，偏差 `+95.0°`）：
    - 求解推力：`cmd = [-11.48 N (左倒), +8.07 N (右正)]`
    - 飞控输出遥测：`/mavros/rc/out` **`SERVO1=1473 μs, SERVO3=1527 μs`**，压差 **`-54 μs`**（左桨反转、右桨正转）。
  - 右转（船头 `89.99°`，目标 `-5.01°`，偏差 `-95.0°`）：
    - 求解推力：`cmd = [+7.90 N (左正), -11.31 N (右倒)]`
    - 飞控输出遥测：`/mavros/rc/out` **`SERVO1=1527 μs, SERVO3=1473 μs`**，压差 **`+54 μs`**（左桨正转、右桨反转）。
- **结论**：左右转向压差严格对称，转向符号完全吻合物理规律，台架实测电机转速一致。

### 3.2 F2：人工超控即时抢占（≤ 0.2 s）
- **测试动作**：在电机处于高转速输出（`CH3=1680 μs`）时，通过遥控器物理开关切入 `HOLD` / `GUIDED` 或拨动保险 `DISARM`。
- **实测时延**：
  - 累计记录 13 次真实物理抢占事件，`regulator.source.jsonl` 中 `issue_steady_ns` 到 `post_publish_steady_ns` 纳秒时标精确回算：
    - 最小抢占时延：**`0.152 ms`**
    - 中位抢占时延：**`0.178 ms`**
    - 最大抢占时延：**`0.208 ms`**
  - 控制器在收到飞控状态离开 `MANUAL` 后的第一时间内，发布 `OverrideRCIn(channels=[0,0...])`，彻底交还通道控制权，电机停转零残留。

### 3.3 F4：里程计断流故障保护（odom_stale > 1.0 s）
- **测试动作**：在船体处于 `ACTIVE`（`CH3=1680 μs` 电机运转）状态下，通过 MAVLink 服务 `/mavros/set_message_interval` 将 `#32 LOCAL_POSITION_NED` 频率设为 `-1.0`（停止发送）。
- **实测时延**：
  - 注入时刻：`t_fault = 20550.123`
  - 故障识别与中位下发：`t = 20551.118`（延迟 **`0.995 s`**，精确命中 `1.0 s` `odom_age` 门限）
  - 中位保护动作：`epoch=28` 下发 `src=failsafe_neutral_hold dir=neutral_pwm ch1=1500 ch3=1500 hold_req=True`，指令下发耗时 **`0.203 ms`**；
  - 飞控状态响应：飞控于 `t = 20551.169`（`+1.046 s`）确认脱离 `MANUAL` 切入 `HOLD`；
  - 释放动作：于 `+1.006 s` 发送 `failsafe_hold_confirmed_release`（`ch1=0, ch3=0`），耗时 **`0.208 ms`**；
  - 恢复测试：重新恢复 #32 消息流至 10.0 Hz，系统识别到有效里程计后，`nav_ready` 恢复 `True`，系统无缝回归安全 `Standby`。

### 3.4 F3：求解器子进程崩溃（kill -9 p1_solver_worker）
- **测试动作**：在 `ACTIVE` 状态下对后台求解器进程 `PID=272853` 注入 `kill -9`。
- **实测时延**：
  - 注入时刻：`t_fault = 20726.766`
  - 控制器响应：控制器在 5Hz 主循环中于 **`+0.154 s`** 捕获 `worker_.exited` 信号，立即生成 `failsafe_neutral_hold` 动作，下发 `1500 μs` 中位并请求飞控切入 `HOLD`；
  - 飞控状态响应：飞控于 **`+0.242 s`** 确认脱离 `MANUAL` 切入 `HOLD`，电机停转；
  - 终态退出：控制器确认通道释放后，按致命故障返回码 `rc=2` 安全退出，`usv-system.service` 干净停机。

### 3.5 F1：控制器进程崩溃看门狗（kill -9 p1_regulator）

- **实测时延**：

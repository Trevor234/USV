## 工具如何记录真实边界

Witness 为固定 POD 数组：256 Tick、128 真实 Submit、128 带候选的最终 Activation 尝试、32 Phase。拒绝 Activation 也记录，accepted 单独计数；无候选 Tick 完整保留。每流使用有界 reservation 与 release publication，close 与活动生产者合用 lifecycle atomic，聚合计数在活动区间内更新。超过容量、非法/未发布行、关闭竞态、关闭后写入和终端文件失败使审计不完整；不扩容、不覆盖旧行。

共享 header 固定 run/boot/contract、diagnostic source/bin、worker bin 和真实 worker instance。driver 先从实际 owned worker capability 得到实例，独立读取文件摘要并锁 expected header；监管器启动时复核实际文件与 `/proc` exe 摘要，运行期间实例不符只使审计失败。Manifest 另外绑定 header、所有业务 include 和 runtime，因此不能仅凭调用者传入 header 字符串授予来源资格。

提交记录位于原 job_id/jobs 授权存储完成后，仍在原业务 mutex 内，DDS 保持锁外。原 source 的 submit_commit_ns 是门前取时，Witness 使用授权存储后的新取时，C0 应验证身份及包围关系，不能要求两时间相等。Activation 记录原最终判定；failed/stopping 是该记录点的独立快照。异步 Sink failed 可能在门判定后变化，`accepted=true` 与 `failed=true` 同时出现不能单独反推违法授权；Phase 的 FinalActivation 观察也不能证明原短路门确实使用 failed 条件。

Tick 的 end 在正常 cutoff 之后或失败退出尾部取时，包含 Decision enqueue、停止处理与调度尾部；原 Decision end 更早，两者不是同一终点。Tick candidate_present 表示参与最终激活的 ticket/candidate 输入对，共享 candidate/admission/pending 状态由实际业务锁下的 Phase 另记。Sink Phase 不取得业务或 preparation mutex，无法知道的槽状态为 null。

默认 witness=false、pause=0。暂停政策为 0..5000ms，仅 no_output/diag5/fault=true/witness=true 能配置正值，一次显式 arm；消费暂停全程在 queue mutex 外，monotonic 截止与 close 取消，取消方与等待方使用同一 pause mutex。此政策截止不能保证调度不超时，后续 R5 必须核对实际 span。关闭期间未满队列的拒绝只记 SourceFailure，实际达到容量才记 QueueOverflow。

所有 tick/prep/Sink producer joined 后才写独立终端文件，POSIX O_EXCL/0600 单次创建，已有文件和符号链接保留。source 失败继续 RC2；source 成功但 audit 写入/完整性失败返回 RC3；两者成功才 RC0。业务不读取 witness 的记录成功或摘要来授权动作。

## 验收覆盖与失败原件

C++ 覆盖各流精确容量/下一条溢出、无候选、非法行、首失败、未 publication、四流并发、关闭竞态、关闭后记录、终端编码/null、已有文件/符号链接/竞争创建、RLIMIT_FSIZE 实际部分写失败；Sink 覆盖默认关闭、模式/fault/上限、一次 arm、暂停期间并发入队、取消释放、真正溢出与 closing 拒绝分账、source 字节保留。Sink 使用 capacity=2 的工具溢出测试，不是 ROS 实际 capacity=512 的 R5 压力证据。

Python 校验固定 schema/types/header/计数/票号/chronology/提交—ready—Activation 关系，至少一个真实 Tick、恰好一次关联首次真实 accepted Activation 的 BusinessReady、全部 producer 时间之后的 Close；重复 JSON key、非有限值、UTF-8、512KiB/深度8/32768节点边界以及 create-only 报告均有测试。它不判 R5、正常合同或 source join。未来 C0 runner 正暂停和原故障参数均在 mkdir/ROS 前拒绝，要求真实 capability 的 layout/startup_ns，提前停机不当作完整声明测量时长；旧 source checker 不放宽。

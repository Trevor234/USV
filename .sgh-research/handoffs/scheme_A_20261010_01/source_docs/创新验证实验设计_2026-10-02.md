## 2. 共用数据与评估口径

### 2.1 一个环境，两类真值

控制器只能看到部署时可用的估计状态和消息；真值位置、真值目标动作、真实模型参数仅供**独立评估器**使用。训练 Critic 可以获得规定的额外信息，但运行 Actor 不得偷看。所有基线使用同一动力学、碰撞几何、状态估计、任务奖励、推进器约束和场景种子。

真实船体碰撞按占据区域相交判定；安全余量违规按预先定义的区域/距离判定；CPA 是预测指标，不能替代真实最小距离。目标船接近零相对速度时，对 TCPA 的数值例外须统一处理并记录。

以**物理闭环时间**计任务效率；训练同时报告环境步数和总计算预算。消融的超参数调优预算相同；若某方法多用联合优化或反事实重算，计入成本。

### 2.2 主指标与偏差控制

| 指标 | 计算对象 | 避免的误解 |
|---|---|---|
| 碰撞/近失/规则事件 | 整个回合，含失败和超时回合 | 不只在成功回合汇总安全率 |
| 备份证书失效接纳数 | 接纳更新/激活新计划的事件 | 用独立约束/包络验证器判断；数值验证不能冒充覆盖所有扰动的证明 |
| 备份实际执行违约数 | 超时/丢包后进入备份的事件 | “备份存在”不等于执行有效 |
| 真实最小船体距离 | 所有连续时间采样的评估轨迹 | 离散节点距离不能代表节点之间的安全 |
| 截止时间违约率 | 每控制步的完整链路 | 仅报告优化器平均时间不足 |
| 任务成功、超时、死锁 | 分开记录 | 通过停船不动得到低碰撞率不能当作成功 |
| 航程、时间、跟踪误差 | 全体回合及成功回合各一份 | 失败不能被选择性排除；成功条件下统计须标明 |
| 实际电能 / 控制代理 | 有电压、电流时积分 $E=\sum VI\Delta t$ | 无电流数据时只称控制努力，不能把 $\sum\|q\|$ 称为电能 |
| 误差界覆盖率 | 预留时序数据、工况分组、闭环访问区域 | GP 后验方差小不等于真实覆盖率高 |
| 干预率/幅度 | 用固定阈值和相同量纲归一化 | 降干预也可能由放宽约束造成，需同时看安全 |

完整时间链包括：状态估计、GP 推断与更新、证书检查、优化、安全后检、发布和执行延迟。报告 P50/P95/P99、最大值、超时率、CPU/内存与活动集规模。$D_{\rm ctrl}$ 是冻结后的截止时间，实验性通过条件为“整条链符合 $D_{\rm ctrl}$ 且超时有有效接续”；不能从此推断确定性最坏执行时间。

证书失效、无法重新验证、真实执行违规是三个不同事件。独立高保真轨迹可以给出真实违规反例，但没有观察到违规不能证明所有扰动下安全；鲁棒证书要由有效可达性/误差界验证，不能以一条数值轨迹当作真值。如果旧固定包络仍有效，GP 均值变化本身不使该证书失效。

### 2.3 概率和“零事故”的声明

每步/每目标的局部违反预算 $\delta_{i,j}$ 如果需要合成有限时域总体预算，可在相应事件成立的前提下用

$$
\Pr(\text{任一违反})\leq\sum_{i,j}\delta_{i,j}.
$$

并不要求事件独立，但需要这些界真的适用于被自适应选择的状态和各个事件；定点后验区间或普通验证集覆盖率不能自动满足这一点。无限时域或多次模型切换需额外论证，不能直接沿用固定时域预算。

若独立同分布的 $n$ 个回合观察到 0 次碰撞，单侧 95% 二项概率上界可由 $(1-p_U)^n=0.05$ 计算：

$$
p_U=1-0.05^{1/n}.
$$

例如 $n=1000$ 时约为 **0.299%**，不是“真实概率为零”。这是公式计算示例，不是本项目结果；相关训练种子、同一个轨迹的重复控制步不一定构成独立回合，不能机械套用。

## 3. A：模型切换与安全备份

### 3.1 先构造反例，后比较算法

**E-A0，三个可诊断反例：**

1. 名义预测在障碍一侧通过，GP 更新后横荡/转艏均值改变；代价变好，但原备份轨迹管与障碍集合相交。
2. 残差随时间漂移，拒绝 GP 更新后旧误差包络仍扩大；若冻结方差后继续用旧证书，应能暴露证书年龄失效。
3. 两个采样点安全，但推进器滞后与较长动作保持使采样间占据区域进入危险区。

用解析构造或高保真积分独立验证。若错误只来自漏检查约束或单位错误，先修实现；不能把实现缺陷叫理论缺口。若所有合理场景下最近方法已解决这些反例，应直接缩减或放弃 A。

### 3.2 必要基线和消融

| 组别 | 方法 | 公平实施要求 |
|---|---|---|
| A0 | 固定已验证宽误差包络 + 固定安全滤波器 | 无在线 GP；参数和安全目标一致，是简单稳健基线 |
| A1 | GP 性能预测更新 + 固定宽安全包络 | 区分“更好的性能模型”与“缩小安全包络”的收益 |
| A2 | 递推 SVGP + 原有安全层，无版本接纳检查 | 这是在 P10 学习结构上加相同安全层的项目基线，不称为原论文完整复现 |
| A3 | GP + Maiworm 风格代价门槛 + 相同安全层 | 说明适用条件；使用可行解代价上界时不能假称最优值定理直接成立 |
| A4 | Koller 风格成熟安全 GP-MPC/备份方法 | 在同一 USV 模型/目标预测下实现适用版本；若需不同假设，单独记录 |
| A5 | 拟议版本一致、年龄修正、保持时间与截止时间检查 | 参数冻结；误差界/约束不得比其他方法秘密放宽 |

对 A5 做四项单因素去除：去版本可行性检查、去年龄漂移项、去采样间余量、去截止时间接续。每次只变一项，备份控制器尽量相同。另加入冻结候选更新的负对照和已知正确残差的理想模型对照；理想模型只用于诊断，不参与部署可用性排名。

### 3.3 首轮最小矩阵

以下是**提议的诊断矩阵**，不是已测结果或当前硬件参数。物理量来自执行前的冻结值：船长 $L$、名义航速 $V$、$T_s$、执行器上界 $\tau_{\rm act,max}$、有效残差幅值/漂移界 $G_b,\rho_b$、状态误差界 $E_b$ 和标签误差界 $E_{\rm label}$。

| 因子 | 首轮建议取值 | 用途 |
|---|---|---|
| 场景 | 静态单障碍；横穿动态目标；窄通道 | 分离几何、时变交通、可行集缩小 |
| 测试模板 | S0 稳态；S1 界内标签扰动；S2 慢漂移；S3 界内阶跃；S4 保持时间延长；S5 漂移与延时联合 | 六模板仅在有效声明界内运行；界外压力另列 |
| 标签扰动 S1 | 抽 1% 样本加入幅值 $0.5E_{\rm label}$ 的误差；对照 0% | 检验模型更新；标签误差界须先冻结并有效 |
| 漂移 S2 | $0.5\rho_b$；持续时间选到漂移累计为 $0.5G_b$ | 检验年龄项，保证域内试验 |
| 阶跃 S3 | 幅值 $0.5G_b$，在避碰已启动时发生 | 检验更新切换，而非从新工况初始开始 |
| 保持时间 S4 | $1.5T_s$；其余模板为 $T_s$ | 在 $T_{\rm hold,max}$ 覆盖时为界内，否则标界外 |
| 联合 S5 | $0.5\rho_b$ 漂移与 $1.5T_s$ 保持时间同时发生 | 若不在声明界内，则移入界外组 |
| 界外 SX | 离群标签幅值 $2G_b$；漂移 $1.5\rho_b$；保持 $2T_{\rm hold,max}$，分开运行 | 诊断失效识别，不要求定理在界外成立 |
| 诱导点数敏感性 | 每通道 $M\in\{16,32,64\}$ | 后续单因素成本/覆盖率试验；不是 P10 最优点数结论 |
| 积分细化 | $T_s/20$，再用 $T_s/40$ 复查最危险案例 | 数值轨迹检验，不能代替形式连续时间界 |

首轮建议 **3 场景 × 6 模板 × 2 个固定场景种子 = 36 个配对案例/方法**；6 组基线合计 216 次短回合，不训练新 RL。可用种子 0–35，明确保存场景–模板–种子映射。后续 M 扫描和消融只在出现机制差异后执行，不把所有维度一次全组合。

该规模用于找机制和估算方差，不足以证明低事故概率；不得根据它直接宣布显著优越。SX 的三种界外子情形单独增加并标识，不并入 36 个保证域案例统计；如果已声明的界不允许某界内模板，就调整数值或移出该组，不能保留“界内”标签。

### 3.4 通过、否决与后续规模

**进入扩大实验的条件（设计目标）：**

- 最近基线确实出现至少一个可重复的证书失效反例，A5 可以解释并识别该事件；独立评估器与内部判定一致。
- 36 个界内诊断案例中，没有接受独立检查判定无效的备份；没有利用放宽约束取得表面收益。
- 对成功率/推进性的配对结果，A5 没有出现明显“全拒绝更新/永久停滞”现象；若只在不可行初始状态失败，要单独分类。
- A5 的 P99 控制链时间不超过冻结截止时间；超时时有效备份接续成功。若无界内超时案例，注入受控超时测试。

“没有观察到无效接纳”仅是诊断通过，不能等于形式保证。扩大阶段先用 100 个独立配对场景估算事件率和方差，再预注册样本量、主要终点和检验；根据希望分辨的最小差异确定规模，不能事后挑显著指标。

**立即停止/改题：** 拟议界不成立、备份区不存在、A4 已覆盖同样机制且开销不高、A5 的收益只来自大幅保守化，或版本检查在截止时间内无法完成。

## 4. B：时效意图与持续避让

### 4.1 基线

| 组别 | 方法 |
|---|---|
| B0 | P7 风格的控制/消息策略 + 与各组相同的本地安全层 |
| B1 | B0 + 时间戳/消息年龄输入 + 相同延迟随机化 |
| B2 | 仅年龄膨胀的目标可达集合，正常模式无意图接续协议 |
| B3 | MLR-DMPC/信息追踪风格的旧新轨迹容错基线，按 USV 动力学公平适配 |
| B4 | 拟议版本/有效期/备份分支 + 规则行为持续性 |

对 B4 分开去除：有效期/年龄传播、旧新版本并集、规则持续性、应急分支覆盖。若使用不同高层策略，增加完全相同固定航点序列下的比较，避免把导航器差异当协议差异。

### 4.2 场景与通信矩阵

先做 2 船对遇、2 船交叉、2 船追越和 3 船交叉；每种场景各取 10 个固定配对案例，共 40 案例/方法。主协议试验先使用固定意图生成器，验证后才训练 MARL。

| 通信因子 | 建议取值 | 必须区分 |
|---|---|---|
| 单向消息延迟 | $0,1,3$ 个消息发布周期 $T_m$ | 不假定发送周期等于控制周期 |
| 独立丢包率 | $0,0.1,0.3$ | 这是工程压力设置，不是观测到的现场丢包率 |
| 突发静默 | $1,3,5$ 个 $T_m$；另加入长于证书有效期的压力段 | 独立丢包与突发故障分开 |
| 时钟偏差 | $0,0.5E_{\rm clock,max},E_{\rm clock,max}$ | 有效期判断要保守考虑偏差 |
| 消息乱序 | 正常；交换相邻两条；旧序号重放 | 序号/版本检查是否有效 |
| 意图更新 | 无变更；未确认变更；第三船触发应急变更 | 应急离开旧管须被原集合覆盖，否则保证条件失效 |
| 目标行为 | 合作；维持航向；在物理界内突然转向 | 不合作目标不能按协作消息承诺处理 |

先分因子扫描，再选机制上最危险的少量组合，不进行无依据的全笛卡尔积。保证域与界外压力分别统计。外部船进入不可避免碰撞状态时，报告初始可行性和行为假设，不要求控制器完成物理上不可能的任务。

### 4.3 主指标和否决

主指标为实际执行轨迹离开他船所用预测集合的次数、误用过期/未确认意图的次数、碰撞/近失、死锁和任务成功。辅指标为避让启动时机、艏向变化、角色抖动、反复改向、字节/消息频率、总计算开销。

规则事件按冻结的场景标签和紧急阶段标注复核；“右转”只是其中一个特征。动作明显性用预定义观测模型/专家标注或检测任务衡量，不等同于随意指定一个角度阈值。

若 B4 相对 B3 没有可靠优势、收益只因提前触发/更大距离，或持续性限制恶化安全，则否决新方法主张，保留协议应用经验。若想宣称任意长丢包仍安全，必须先证明可持续备份和外部交通条件；目前无此依据。

## 5. C：联合盾与信用估计

### 5.1 最小机制实验

先用 2 船，每船 **3 个相同的高层动作**，例如左侧航点、保持航点、右侧航点；所有组使用同一低层 MPC/盾。只枚举 9 个联合动作，验证联合可行集和完整转移，而非一开始训练连续推进器策略。

记录每个联合建议动作对应的联合执行、即时奖励、盾下一内部状态和目标转移。比较本船 3 个动作的价值排序随另一船动作是否变化；出现反转只能说明该环境可能有单调表示限制，不能直接证明 QMIX 训练一定失败。

同一执行动作但奖励/通信/记忆不同，不合并；若使用近似等价类，对误差进行独立统计。基线为：正确的带盾 MAPPO、以建议动作定义闭环 Q 的 COMA、盾上下文增强的 COMA、拟议完整联合反事实/等价聚合；离散 QMIX 作为表示能力对照。

### 5.2 训练与消融

暂定首轮 5 个训练种子，各组相同采样步数、网络规模和调优预算，另外报告实际总计算时间；每个种子在独立的同一组 100 个评估场景上测试。它是训练稳定性诊断建议，不是显著性功效计算。

消融区分：额外 Critic 输入、完整联合重算、精确等价聚合、近似聚合。PPO 样本存建议动作及其旧策略密度；环境执行盾输出；模型/盾版本冻结于一轮采样和优化中，版本变化要单独标记并处理。

主指标为达到预设成功率所需样本和计算、配对回报、优势估计方差、反事实 Q 误差；同时保持安全指标与干预定义一致。若相同建议产生同一闭环结果，正确的原 COMA 已能学到这一点，聚合只能争取效率收益，不能声称自动修复原方法偏差。

**否决：** 相同计算预算下无优势；增益仅来自更多信息；反事实模型误差导致偏差；安全改进由更强盾而非信用估计产生。安全层的控制理论结论由 A/B 或独立安全层提供，C 的收敛/方差结果不能替代碰撞保证。

## 6. 需要保存的实验记录

执行后在项目统一实验目录保存 design、冻结参数、环境版本、命令日志、种子/场景映射、每步日志、结果和复盘。用户本次指定创新目录，本文件属于研究设计交付；未来真实执行的数据应按 sgh-experiment-design 放入 `.sgh-research/experiments/<实验ID>/`，不要将未跑的占位值填入 results。

每步日志至少包括：时间/控制截止时间、估计与真值、左右推进器建议和执行、输入变化率、模型版本、GP 均值/误差界、初始与障碍集合摘要、计划/证书有效期、消息序号及年龄、会遇角色、优化状态、约束残差、接纳/拒绝原因、备份模式、真实安全事件。

结果表分 **保证域内、界外压力、初始不可行、数值/实现错误** 四类。复盘先检查基线公平性、信息泄漏和参数量纲，再归因于方法。最终论文同时披露失败情形、保守性成本、所有训练种子和真实端到端时间。

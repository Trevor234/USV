## 运动复算：观察与推断分开

速度仍采用输入定义 `hypot(state[3],state[4])`，即原始平面 twist 范数，不将 `state[3]` 单独认证为前向 u。位置轨迹从 `state[0:2]` 取值；`state[2]` 按输入提取约定视作 yaw 进行展开诊断，但本包没有原始 quaternion 用于独立复核其语义，six-state 约定仍未认证。course 是相邻位置差的方向，与船体 yaw 是不同量。

三点曲率使用 `2 cross(B−A,C−A) / (|AB| |BC| |AC|)`；任一距离 ≤ `1e-6 m` 时跳过。全量复算的 count / min / max 与输入三包四个 odometry 摘要一致（浮点容差 `1e-12`）。median / p95 是本次分析推断，采用 sorted rank `(n−1)q` 的线性插值，分别给 signed 与 absolute 值。三点曲率对微小位移非常敏感；极大 max_abs 不自动证明真实转弯。

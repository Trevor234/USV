## 二、辨识流程（三个阶段，约 30 分钟水试）

### Stage 1：推进器建模（PWM→RPM + 左右不对称）

**目标**：拟合新推进器的 `RPM = a1·x + a2·x²`（x=PWM−1500）和左右增益比。

**数据要求**：任意机动 5 分钟以上，只要 ESC 遥测有 RPM 数据即可。

**操作**：
1. MANUAL 模式，随意开船 5 分钟（不同油门档位各跑一段）
2. 确认 ESC 遥测 RPM 有值（`ESC.RPM` 字段非零）

**处理**：
```bash
python3 scripts/parse_log.py <bin> data_parsed/<名>.npz
python3 scripts/fit_thruster.py data_parsed results/<日期>/
```

**产出**：`thruster_model.json`（分桨 a1/a2/R²、增益比、掉速点检测）

**验收**：R² ≥ 0.95；左右增益比 CI 收敛

---

### Stage 2：纵向辨识（K_T + Xu/Xuu 定稿）

**目标**：推力绝对标度 K_T + 纵向阻力曲线定稿（9-03 未完成的部分，本次补上）。

**数据要求**：两个机动——

**M1 定油门直航（4 档）**：
1. MANUAL 模式，油门推到预设档位后**锁死不动**
2. 档位：~30% / 50% / 70% / 100%（PWM ≈ 1650/1750/1850/2000）
3. 每档保持直线 30 秒（舵修正 <100us）
4. 完成一轮后掉头往返再做一轮（抵消风/流）

**M2 空挡滑行（coast-down，最关键）**：
1. 加速到 ≥2.5 m/s
2. **油门杆直接回中（1500），之后全程不碰油门**
3. 舵回中，让船自然滑行到 <0.3 m/s（约 15-25s）
4. 重复 3 次，初速分别 ≈3.0 / 2.5 / 2.0 m/s

**处理**：
```bash
python3 scripts/fit_surge_coast.py data_parsed results/<日期>/   # 滑行阻力
python3 scripts/fit_surge_shoot2.py data_parsed results/<日期>/   # 平衡曲线+K_T
```

**产出**：`surge_params.json`（K_T、Xu、Xuu、T_max）

**验收**：平衡曲线 R² ≥ 0.95；滑行回归 R² ≥ 0.90；Xu/Xuu 符号正确且 95% CI 不含 0

> **9-03 教训**：当时没有 M1/M2 机动（数据是为功能测试采集的），导致 K_T 仍是假设值、
> Xu 不可辨。本次务必优先保证 M2 滑行段。

---

### Stage 3：艏摇辨识（Nr/Nrr/Iz_eff 精化）

**目标**：用 Z 字机动精化艏摇参数（9-03 已拟合但 R²=0.35，本次改善数据质量）。

**数据要求**：

**M3 定油门 Z 字机动**：
1. MANUAL 模式，油门锁定 50%（第二轮 70%）
2. 方向舵 ±500us 左右切换，每侧保持 3-4 秒
3. 连续 8-10 个往复（约 90 秒），油门全程不动

**处理**：
```bash
python3 scripts/fit_yaw_regress.py data_parsed results/<日期>/
```

**产出**：`yaw_params.json`（Iz_eff、Nr、Nrr、tau_r）

**验收**：打靶回放中位 RMSE < 12°/s；开环全工作点稳定

> **9-03 结果**：Iz_eff=5.537, Nr=3.105, Nrr=0.710（已写入 usv_params.yaml）。
> 换推进器后这些值预计变化不大（船体属性），但 K_T 变了会改变 tau 的标度，
> 建议重跑确认。

## 四、上电前检查清单

- [ ] **ESC 遥测三字段确认**：试录 1 分钟，检查 ESC 消息 RPM/Volt/Curr 都有真实值
      （9-03 数据 Volt 全 0——若能配置电压上报请开启）
- [ ] 日志速率：IMU/ESC 全速（~73Hz），RCOU/STER/THR 使能
- [ ] 罗盘校准完成；磁偏角设置正确（上海约 5°W）
- [ ] GPS：≥20 星、HDOP <1.0 再开始
- [ ] 电池：同一起始电量（≥28.0V），全程记录电压
- [ ] 环境：风速 ≤3 级、无明显水流、水域开阔
- [ ] 每个机动段之间留 10s 静泊间隔（便于自动分段）
- [ ] 遥控链路全程在线（MANUAL 操作需要）
